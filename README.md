# Port Azahar 3D

Port Azahar 3D is an original, fully 3D open-world crime game built from scratch for the make.fun competition using Three.js and modern WebGL. Set in the vibrant coastal metropolis of Port Azahar, players step into the shoes of Dario Venn, a streetwise driver taking on dangerous jobs across five distinct districts: the industrial Docks, neon-lit Neon Mile, historic Old Town, breezy Marina, and upscale The Hills.

## Features
- **Real 3D Open World**: Built with Three.js featuring perspective cameras, procedural city grid, extruded buildings with district-specific facades, lit windows by night, rooftop props, and glowing neon storefronts.
- **Dynamic Systems**: Full day/night cycle, dynamic lighting, weather/time moods, traffic AI, wandering pedestrians, 5-star wanted system with police pursuit AI, combat (melee and firearm with muzzle flash), and comprehensive HUD with mini-map and speedometer.
- **Mission Campaign**: 5 narrative missions ("First Run", "Borrowed Wheels", "Heat", "Three Drops", "Last Boat") complete with dialogue banners, mission objectives, timers, and free-roam mode upon completion.
- **Audio & Visual Polish**: WebAudio-synthesized sound effects (engines, sirens, gunshots, radio bassline), particle effects, skid marks, headlight cones, and smooth chase camera physics.

## Run It

To play Port Azahar 3D locally:

```bash
node serve.ts
```

Then open your browser at **http://localhost:8080**.
